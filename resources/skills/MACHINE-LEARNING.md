# Skill: Machine Learning

## Core Philosophy
- **Data-Centric AI:** Prioritize the quality and diversity of data over model complexity.
- **Reproducibility:** Ensure all experiments, data pipelines, and model training runs are fully reproducible.
- **Ethics & Fairness:** Proactively identify and mitigate bias in datasets and model predictions.

## Implementation Rules
- **Data Pipelines:** Build robust, versioned pipelines for data collection, cleaning, and feature engineering (DVC, MLflow).
- **Model Training:** Use standardized frameworks (PyTorch, TensorFlow, Scikit-learn) and track hyperparameters.
- **Evaluation:** Utilize appropriate metrics (Precision, Recall, F1, RMSE) and validation strategies (Cross-validation).
- **Inference:** Optimize models for target environments (TensorRT, ONNX, TFLite) and implement efficient serving (vLLM, Triton).
- **Vector Databases:** Use vector stores (Pinecone, Milvus, Qdrant) for RAG and similarity search.

## MLOps
- **Continuous Monitoring:** Track model performance and data drift in production.
- **Version Control:** Version control models and datasets alongside code.
