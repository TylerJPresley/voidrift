# Skill: Internationalization (i18n)

## Core Philosophy
- **Global-Ready:** Design for the world from Day 1. Never hardcode strings, formats, or cultural assumptions.
- **Cultural Adaptability:** Respect regional differences in currency, dates, numbers, and linguistic nuances.

## Implementation Rules
- **Externalized Strings:** Store all user-facing text in localized resource files (JSON, YAML, PO).
- **Formatting:** Use standard libraries (Intl API, Moment/Date-fns) for locale-aware formatting of dates, times, and currencies.
- **RTL Support:** Ensure the UI supports Right-to-Left languages (Arabic, Hebrew) through logical CSS properties.
- **Pluralization:** Handle complex pluralization rules across different languages (beyond just singular/plural).
- **Unicode:** Use UTF-8 for all data storage, transmission, and processing.

## Localization (L10N)
- **Context for Translators:** Provide developer notes/context in resource files to ensure accurate translations.
- **Dynamic Content:** Ensure dynamically generated content is properly translated and formatted for the target locale.
