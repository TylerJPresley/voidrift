# voidrift

VoidRift CLI — the terminal agent harness on the VoidRift core SDK.

Part of VoidRift, a local-first, model-agnostic AI agent harness. Status: pre-release (0.4.0), under active development.

## Requirements
- Node.js >=24
- `@voidrift/core` `^0.1.0`, which is not published to npm yet. Until it is, link a local checkout of the core repository (`npm link @voidrift/core`).

## Build from source
```bash
git clone https://github.com/TylerJPresley/voidrift.git
cd voidrift
npm install
npm run build
npm test
```
